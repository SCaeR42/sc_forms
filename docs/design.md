# Независимый пакет SC Forms

## Назначение
Перенести формы Joomla-плагина sc_forms в самостоятельный пакет для любого PHP-сайта. Пакет не загружает Joomla и не требует jQuery.

## Выбранный подход
Выбран самостоятельный пакет PHP + JavaScript + CSS с собственной модалкой. Альтернатива — отдельный обработчик с использованием текущей jQuery-модалки — потребовала бы переносить зависимости шаблона сайта.

## Состав и подключение
- PHP 8.1 или новее; PHPMailer устанавливается через Composer, инструкция включает подготовку пакета на компьютере для хостинга без Composer.
- public/: PHP-обработчик, JavaScript, CSS и демонстрационная страница.
- src/ и конфигурация находятся вне публичной папки; инструкция описывает размещение на обычном хостинге.
- Пять форм: consultation, requestdemo, becomeclient, partner, feedback. Сохраняются состав полей, тексты, адресаты и темы из оригинальных настроек.
- Подключение JS и CSS, настройка URL обработчика, кнопки с data-sc-form="consultation". Публичный метод SCForms.open(name), показ встроенных форм через data-sc-form-inline.
- При наличии jQuery поддерживается старое событие openForm и кнопка .js-showForm-consultation. Старый form.js одновременно не подключается во избежание двойных запросов.

## Поведение
Обработчик возвращает HTML выбранной формы; браузер открывает собственное модальное окно. POST передаёт scform[...] и имя формы. Ответ JSON содержит CODE и mess, дополнительно ошибки полей. Ошибки оставляют введённые данные на месте, успех показывает исходное сообщение. Закрытие кнопкой, Escape и фоном; управление фокусом и восстановление прокрутки. Встроенная форма использует тот же обработчик.

## Письма и настройки
Отдельная конфигурация SMTP: сервер, порт, TLS/SMTPS, пользователь, пароль, отправитель и адресаты. Пароль задаётся через окружение либо закрытый локальный файл. Отправка через PHPMailer с проверкой TLS-сертификатов. Письмо включает поля, IP и источник; значения экранируются. Email посетителя используется в Reply-To, а отправитель берётся из конфигурации. Ошибки SMTP журналируются на сервере без выдачи реквизитов посетителю. Перенаправление писем по отладочной cookie не переносится.

## Проверки и защита
Имена форм выбираются только из разрешённого списка. На сервере проверяются обязательные поля, email, согласия, типы и длины значений. Используются ограничение размера запроса, скрытое антиспам-поле и ограничение частоты отправки с файловым хранилищем вне публичной папки. Чужие источники разрешаются явным списком; настройка по умолчанию — один сайт. Для отправки используется короткоживущий подписанный токен формы, не зависящий от сторонних cookie. CORS сам по себе не считается защитой от спама.

## Проверка результата
Проверка синтаксиса PHP и JavaScript, серверных правил и HTTP-ответов. Интеграционная отправка через локальный тестовый SMTP без писем реальным адресатам. Проверка открытия, закрытия и отправки в браузере при доступности окружения. Доставка через рабочий SMTP проверяется только при наличии реквизитов и отдельного указания отправить тестовое письмо.

## Границы
Не меняются Joomla-плагин и текущий шаблон. Готовый пакет и инструкция выдаются отдельно в outputs. Подмена тегов Joomla {SCForm} реализуется явными HTML-контейнерами; автоматического перехвата вывода чужого PHP-сайта нет. Дизайн использует собственные изолированные стили, близкие по структуре к исходным формам, без зависимости от Bootstrap. CAPTCHA, загрузка файлов, база заявок и административная панель не входят в пакет.

## Решения исполнителя
PHP 8.1+, PHPMailer, изолированные стили, подписанные токены, файловое ограничение частоты и отдельная публичная папка предложены исполнителем. Рабочие SMTP-реквизиты в пакет не включаются.
