# Проверка сборки

Дата: 9 ноября 2026.

- PHP 8.4.12: проверки форм, валидации, кодировки, токенов, источников, ограничения частоты и HTTP-контракта проходят.
- PHPMailer 7.2.0: отправка через настоящий локальный SMTP-протокол и отказ адресата проверены. HTML, UTF-8, получатель, From и Reply-To проверены. Тестовый сервер письма не пересылает.
- Полный путь HTTP → PHP-обработчик → PHPMailer → локальный SMTP проверен, включая отрицательные запросы и ограничение тела.
- JavaScript: синтаксис проверен; DOM-тесты подтверждают встроенную форму, модалку, сохранение ввода при ошибке, блокировку двойного нажатия, успех, возврат фокуса и гонки закрытия/открытия.
- Независимый обзор кода выявил гонку отложенного события close. Регрессионный тест воспроизвёл ошибку до исправления и проходит после него. Других существенных замечаний обзор не выявил.
- Composer audit: известных уязвимостей установленных зависимостей не обнаружено.

Ограничения проверки: в окружении не удалось запустить Chrome, а встроенный браузер не смог открыть локальный HTTP-сервер. Поэтому внешний вид, нативная блокировка фокуса dialog и полный браузерный тест не подтверждены. DOM-тест эмулирует жизненный цикл dialog, не его визуальный рендеринг. Рабочий SMTP и фактическая доставка внешнему получателю не проверялись; реальные письма не отправлялись.

При проверке большого POST обнаружена недоступная временная папка локальной PHP-конфигурации. Изолированные тестовые серверы используют собственную папку var; рабочему хостингу нужна корректная sys_temp_dir. Предоставлена .user.ini с отключённым выводом ошибок. Тесты с HTTP запрещают запуск при наличии config.local.php, чтобы исключить использование рабочей почты.

Пакет собран в outputs/sc_forms. Запрошенное размещение W:/Projects/sc_forms не выполнено: приложение не предоставило право записи на этот путь. Исходный Joomla-сайт не изменялся.
